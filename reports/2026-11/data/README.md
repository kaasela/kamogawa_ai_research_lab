## 観測条件（全セル共通）
- 対象：ChatGPT（Web版・**gpt-6**）、一時チャット（ログイン状態）
- n：各セル20回、キーワード型クエリ、連続実行（座禅・日本語は記憶オフ確認後にやり直した20回）
- 実行地：京都市、期間：**2026-10-22〜24**、観測者：単独
- 3カテゴリ（茶道 / 着物・和服 / 座禅）× 4言語（ja / en / zh-Hans / zh-Hant）＝12セル
- 記憶（メモリ）機能：座禅4セルはオフ。茶道・着物8セルは状態不明（本文付録A-2）

## 第2号との違い（必ず読んでください）
**モデルが変わりました。** 第2号は GPT-5.6 Sol、本号は gpt-6 です。
**引用元の取得方法も変わりました。** 第2号までは回答の脚注として表示された引用を記録していました。
本号は、応答に付く安全なURLのうち引用元を示す印（utm_source=chatgpt.com）が付いたものの集合を記録しています。
タイトルとURLの対応は取れず、並び順は安定しません。1回あたりの引用は第2号の2.8件から6.5件に増えました。
2期間の差分は、この2つの変更と交絡しており、切り分けられません。

## 注記
- 事業者個体名は含めず、ドメインのみ公開（ドメインは公開情報）
- 実行地は「京都市」に粗化
- 同一実行内で同じドメインが複数回引かれても1件と数える（ドメイン単位）
- 「Google地図・検索（別掲）」は内容を載せるサイトではないため6分類に入れず、構成比と送客型比率の分母に入れていません（`summary_by_cell.csv` では pct を空欄にしています）。未分類は分母に入れています
- `summary_by_cell.csv` の pct は種別ごとに四捨五入しているため、メディアとOTAを足した値と、本文の送客型比率とで0.1ポイント前後の差が出ることがあります
- 事業者情報カード経路（placecards.csv）は、本号では記録形式の変更により収録していません
- 地図カードと本文の食い違い（本文第5章）の回ごとの分類は、事業者名を含む記録に基づくため、本データには含めていません
