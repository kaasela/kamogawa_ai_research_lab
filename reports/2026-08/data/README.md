# Kääselä Monthly Report #000 公開データ（2026-08）

Kamogawa AI Search Lab（Kääselä）／ kaasela.com
生成AIが京都の体験型事業者を各言語でどう引用するか、の観測データ（無償公開）。

## 第2版について（2026年8月20日改訂）

初版のデータは、回答中に事業者名とともに表示される登録情報（プレイスカード）を、
引用として数えていました。これは検索にもとづく引用とは別の経路です。

第2版では両者を分離しています。

- `data.csv` は**引用経路のみ**（脚注引用＋行内引用）に修正しました（1023行→764行）
- プレイスカードは削除せず、`placecards.csv` として**独立した指標**に分離しました（329行）

カードのドメインは98〜100%が事業者自身のサイトであるため、初版ではカードが出やすいセルほど
自社サイトの比率が高く出ていました。この変更により、12セル中6セルで最も多く引用された種別が
入れ替わっています。詳細は本文レポートの「改訂記録」を参照してください。

## 収録
- `data.csv` … 1行 = 1観測（セル×実行回×引用ドメイン）。**引用経路のみ。計764行**
- `placecards.csv` … 1行 = 1観測（セル×実行回×カードのドメイン）。計329行
- `summary_by_cell.csv` … セル別の引用元種別構成比（引用経路）

本文レポート：<https://kaasela.com/reports/2026-08/>

## 観測条件（全セル共通）
- 対象：ChatGPT（Web版・GPT-5.5）、一時チャット（ログイン状態）
- n：各セル20回、キーワード型クエリ、連続実行
- 実行地：京都市、期間：2026-07、観測者：単独
- 3カテゴリ（茶道 / 着物・和服 / 座禅）× 4言語（ja / en / zh-Hans / zh-Hant）＝12セル

## 列（data.csv / placecards.csv 共通）
| 列 | 意味 |
|---|---|
| cell | セルID（例 QT-JA＝茶道・日本語）|
| category | QT=茶道 / QK=着物 / QZ=座禅 |
| language | ja / en / zh-Hans / zh-Hant |
| run | 実行回（1〜20）|
| source_domain | ChatGPT が引用した／カードで表示したドメイン |
| source_type | 公共 / 自社 / OTA / メディア / ディレクトリ / UGC（分類基準は本文方法論章）|

## 注記
- 事業者個体名は本CSVには含めず、ドメインのみ公開（ドメインは公開情報）
- 実行地は「京都市」に粗化
- 主指標は引用元分布（`data.csv`）。カード経路（`placecards.csv`）は別指標として扱う
- 個体出現率は n=20 では上位グループのみ判定可（本文参照）
- 同一実行内で同じドメインが複数回引かれても1件と数える（ドメイン単位）
