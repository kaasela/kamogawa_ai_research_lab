## 観測条件（全セル共通）
- 対象：ChatGPT（網頁版・GPT-5.5）、一時チャット/ログアウト状態
- n：各セル20回、キーワード型クエリ、連続実行
- 実行地：京都市、期間：2026-07、観測者：単独
- 3カテゴリ（茶道 / 着物・和服 / 座禅）× 4言語（ja / en / zh-Hans / zh-Hant）＝12セル

## 列
| 列 | 意味 |
|---|---|
| cell | セルID（例 QT-JA＝茶道・日本語）|
| category | QT=茶道 / QK=着物 / QZ=座禅 |
| language | ja / en / zh-Hans / zh-Hant |
| run | 実行回（1〜20）|
| source_domain | ChatGPT が引用したドメイン |
| source_type | 公共 / 自社 / OTA / メディア / ディレクトリ / UGC（分類基準は本文方法論章）|
