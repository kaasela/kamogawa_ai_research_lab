## 観測条件（全セル共通）
- 対象：ChatGPT（Web版・**GPT-5.6 Luna**）、一時チャット（ログイン状態）
- n：各セル20回、キーワード型クエリ、連続実行
- 実行地：京都市、期間：**2026-08-18〜20**、観測者：単独
- 3カテゴリ（茶道 / 着物・和服 / 座禅）× 4言語（ja / en / zh-Hans / zh-Hant）＝12セル

**第0号との違いはモデルです。** 第0号は GPT-5.5、本号は GPT-5.6 Luna で観測しています。
2期間の差分はこのモデル変更と完全に交絡しており、ウェブ側の変化と切り分けられません。
本文レポートの「適用範囲・限界」を参照してください。

## QZ-EN（座禅・英語）は n=19 です
20回中1回（RUN 10）の記録に貼り付けミスによる破損が見つかったため、**当該回を無効とし、
取り直さずに n を減らして公開しています。** 破損後に取り直した回を採用するかどうかで
順位判定の結果が変わることを確認しており、補填は中立な操作ではないと判断しました。
「未実行」とは区別しています。他の11セルは n=20 です。

## 列（data.csv / placecards.csv 共通）
| 列 | 意味 |

## 注記
- 事業者個体名は本CSVには含めず、ドメインのみ公開（ドメインは公開情報）
