隱私政策

Kääselä 2026-11-04 最後更新

本站收集的個人資訊僅限於newsletter訂閱表單中填寫的電子郵件地址，不收集其他任何個人資料。

1. 收集的資訊

本站收集的個人資訊僅限於newsletter訂閱表單中填寫的電子郵件地址。不收集姓名、地址、電話號碼等資訊。

免費檢查工具（僅日文）會以 KaaselaChecker 的名義，從本站伺服器取得您所輸入網域的公開檔案（robots.txt、sitemap.xml、llms.txt 與首頁），並在畫面上顯示結果。您輸入的網域與結果不會被保存，網域也不會出現在 URL 中，不會寫入營運者的日誌。為限制過度使用，僅暫時處理 IP 位址，不保存。

2. 使用目的

你提供的電子郵件地址僅用於在Monthly Report發布新一期時通知你。不用於廣告投放、出售給第三方，也不用於聯繫你其他事項。

3. 第三方提供

訂閱表單的收發使用 Netlify, Inc. 的表單功能（Netlify Forms）。填寫的電子郵件地址會經由 Netlify 的伺服器送達本站營運者。除此之外不會向任何第三方出售或共享。

4. 關於Cookie與存取分析

本站不使用Cookie。為了解網站的閱讀情況，本站使用不依賴Cookie的存取統計服務GoatCounter（goatcounter.com），僅統計被瀏覽的頁面、來源網址、瀏覽器與作業系統類型、螢幕尺寸和大致的國家/地區，不保存IP位址或其他可識別個人的資訊。本站不使用Google Analytics等廣告追蹤腳本。Google Search Console僅供營運者本人管理網站使用，不會收集訪客的個人資料。

本站出於研究目的記錄AI爬蟲（如GPTBot、ChatGPT-User）的User-Agent存取日誌，該記錄不針對人類訪客，也不包含任何可識別個人身份的資訊。

5. 資料保存與刪除

已登記的電子郵件地址會保存至通知目的所需的期限。如需刪除登記，請發送電子郵件至下方聯絡地址。目前尚未建立自動退訂機制，刪除申請請透過電子郵件回覆或直接來信處理。

6. 聯絡方式

關於本政策及個人資訊處理的諮詢，請聯絡 kamogawa.ai.lab@gmail.com。
